# 🎬 Mong Ha Pong

A cinematic-style personal portfolio built with React — designed to showcase identity, skills, and projects in an immersive and visually engaging experience.

🔗 **Live Demo:** [mong-ha-pong.vercel.app](https://mong-ha-pong.vercel.app)

---

## ⚡ Overview

**Mong Ha Pong** is a personal portfolio that goes beyond the traditional static resume website. The focus is on crafting a modern, atmospheric UI experience that blends:

- 🎨 Visual UI design
- 🎞️ Motion & interaction
- 🧬 Personal branding

...into one cohesive interface.

---

## 🧠 Concept

This project is built around the idea of a **"cinematic developer identity system"** — where the portfolio feels more like an experience than a webpage.

Instead of plain sections, the user is guided through:

- Visual storytelling
- Interactive UI elements
- Smooth transitions and motion-based layout

## 🚀 Getting Started

### Prerequisites

- Node.js
- Python 3.x

### Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate       # Windows
# source venv/bin/activate  # macOS/Linux
uvicorn app.main:app --reload --port 8002
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
